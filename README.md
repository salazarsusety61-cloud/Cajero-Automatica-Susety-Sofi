# Cajero Automático # Parte B
Proyecto de cajero automático en Python con guardado de datos en archivo JSON.

## Funcionalidades
- Registrar nuevos clientes
- Iniciar sesión con número de cuenta y PIN
- Consultar saldo
- Retirar dinero (múltiplos de $1.000)
- Depositar dinero
- Cambiar PIN
- Datos guardados automáticamente en JSON
